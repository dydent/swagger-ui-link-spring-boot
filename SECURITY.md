# Security Policy

## Supported versions

Until the first stable release, security fixes are made on `main`. After release, only the latest published minor line is supported.

## Reporting a vulnerability

Do not open a public issue. Email `dydent.github@outlook.com` with the affected version, impact, reproduction steps, and any suggested mitigation. Please allow time to confirm the report and coordinate a fix before public disclosure.

Never include real credentials or private application logs in a report.
