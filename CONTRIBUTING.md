# Contributing

Thank you for helping improve Swagger UI Link Spring Boot Starter.

Before opening a pull request:

1. Open an issue for behavior or compatibility changes so the small project scope stays clear.
2. Keep changes focused and avoid adding a production dependency when Spring Boot or the JDK already provides what is needed.
3. Add or update the smallest test that proves the behavior.
4. Run the four compatibility commands in the README.
5. Update the README when a public property or supported configuration changes.

Pull requests should explain the user-visible problem, the chosen behavior, and the verification performed. By contributing, you agree that your contribution is licensed under Apache License 2.0.
